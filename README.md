Calculator

This is a simple calculator project made for **The Odin Project**.

I created this project to practice my **HTML, CSS, and JavaScript** skills.

Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear button
- Delete button
- Decimal numbers
- Simple calculator display
- Handles division by zero

Built With

- HTML
- CSS
- JavaScript

What I Learned

While making this project, I learned:

- How to use JavaScript functions
- How to use event listeners
- How to work with buttons
- How to update the calculator display
- How to perform mathematical operations
- How to use `if` statements
- How to work with variables
- How to handle user input

How It Works

1. Click a number button.
2. Choose an operator such as `+`, `-`, `×`, or `÷`.
3. Enter another number.
4. Click the `=` button.
5. The calculator shows the answer.

Important

This calculator does **not** use `eval()`.

The mathematical operations are handled using JavaScript functions.

Project Purpose

The main purpose of this project is to improve my JavaScript fundamentals and understand how a calculator works.
